# results/

Committed result rows: `<set>/<model>.json`, one model on one set, written by `lrbench results add` and validated
by `lrbench results check`. `sets.json` holds the set cards, and `SUMMARY.md` is generated by
`lrbench results render`. `private/` is git-ignored and holds rows for unreleased models and internal-only data.

How to add a row, a set or new curves: [docs/results.md](../docs/results.md). Write local run outputs to `runs/`,
not here.
